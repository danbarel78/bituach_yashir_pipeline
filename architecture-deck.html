The model

Three rules make the flow predictable

Git is the truth
branches + tags
  • The developer never edits a version.
  • `release.sh` is the only bump.
  • Rollback is a Git revert.
Environments are fixed
Argo CD tracking
  • dev and staging track `develop`.
  • prod tracks `main`.
  • A release build writes only the staging overlay.
Images are immutable
tag + digest
  • One tag per build; the overlay pins the digest.
  • `latest` is forbidden.
  • Prod changes only after a manual Sync.
⚡Staging shares the develop branch, but not the same directory: a develop build touches only overlays/dev; a release build touches only overlays/staging.

Step 5 · housekeeping

Back-merge or the next develop build fails

main
v1.0.0 + pin
merge
develop
base_version 1.0.0
next build
1.0.1-dev.M
dev deploys
Commands
git switch develop git merge --no-ff main git push origin develop git push origin --delete release/1.0.0
Why it matters
  • Without it: `0.0.1-dev.N` < `v1.0.0` → monotonicity failure.
  • With it: next build is `1.0.1-dev.M`.
  • Conflict rule: keep develop overlays; take main `base_version` + `CHANGELOG`.
⚠This is not optional. A release without the back-merge leaves develop unable to build.

Failure modes

What the operator should check first

NOT_BUILT
Release branch cut from a `[skip ci]` pin. Current pipeline builds release branches; merge develop if the branch has the old Jenkinsfile.
DUPLICATE
Two builds for one revision. The folder scan is the only trigger now; per-branch polling was removed.
403
The bot cannot push the digest commit to main. Allow the credential to bypass branch protection.
VERSION
`does not sort above newest tag` — the back-merge to develop is missing.
ARGO
`path does not exist` — prod tracks main before the release merge. `OutOfSync` is expected until Sync.
SMOKE
Smoke fails from Jenkins only: `host.docker.internal` / IPv4 resolution. Check `SMOKE_RESOLVE_IP`.
ℹBoth defects found during the live run are fixed in the pipeline: `[skip ci]` is scoped to develop/main, and per-branch polling was removed to prevent duplicate builds.
